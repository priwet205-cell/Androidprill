# Мой архив — Android-приложение

Личное хранилище информации с неограниченной вложенностью разделов.

## Что умеет

- **Разделы и подразделы** любой глубины. На пустом главном экране — большая кнопка «Добавить раздел».
  Внутри раздела кнопка «Добавить» создаёт подраздел или запись.
  Долгое нажатие на раздел — переименовать / удалить (удаляется вместе со всем содержимым).
- **Записи**: название, описание, фотографии, видео и любые файлы (docx, pdf, mp4, mp3, txt…).
  Файлы копируются во внутреннюю память приложения, поэтому не пропадут, если исходник удалить.
- **Просмотр внутри приложения**:
  - фото — полноэкранно, листание, масштаб щипком и двойным тапом;
  - видео и аудио (mp4, mkv, webm, 3gp, mp3, m4a, ogg, wav…) — встроенный плеер;
  - PDF — постранично;
  - DOCX — текст с форматированием, заголовками, списками, таблицами и картинками;
  - TXT/CSV/JSON/MD — как текст (UTF-8 или Windows-1251).
  - Остальные форматы (старый .doc, .xlsx, .pptx…) открываются кнопкой «Открыть в другом приложении».
- Работает без интернета, данные хранятся только на телефоне (база Room/SQLite).

Требования: Android 8.0 (API 26) и новее.

## Как собрать APK

### Вариант 1. Android Studio (проще всего)
1. Установите [Android Studio](https://developer.android.com/studio).
2. File → Open → выберите папку `MyArchive`. Дождитесь окончания синхронизации Gradle
   (первый раз скачиваются зависимости, нужен интернет).
3. Подключите телефон по USB (в телефоне включите «Для разработчиков» → «Отладка по USB»)
   и нажмите зелёную кнопку ▶ Run — приложение установится на телефон.
4. Чтобы получить файл APK: Build → Build App Bundle(s) / APK(s) → Build APK(s).
   Файл появится в `app/build/outputs/apk/debug/app-debug.apk` — его можно скинуть на телефон и установить
   (разрешите установку из неизвестных источников).

### Вариант 2. Командная строка
Нужны JDK 17+ и Android SDK (путь в `local.properties`: `sdk.dir=/путь/к/Android/sdk`).

```bash
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
```

### Вариант 3. GitHub Actions
Если загрузить проект в репозиторий на GitHub, workflow `.github/workflows/build-apk.yml`
соберёт APK автоматически: вкладка Actions → последний запуск → артефакт `MyArchive-apk`.

## Структура кода

```
app/src/main/java/com/artem/myarchive/
├── App.kt, MainActivity.kt
├── data/            база Room: разделы, записи, вложения; копирование файлов
└── ui/
    ├── SectionScreen.kt     главный экран и экран раздела
    ├── EntryScreen.kt       просмотр записи
    ├── EntryEditScreen.kt   форма добавления/редактирования записи
    └── viewers/             просмотр фото, видео/аудио, PDF, DOCX, текста
```
